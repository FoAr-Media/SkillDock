Features

Everything Claude reads, in one place

Skills pile up across user, project, plugin and managed scopes. SkillDock shows you what Claude actually sees, and changes it only when you say so.

A marketplace that shows its work

Live discovery from public GitHub repositories, plugin marketplaces and the MCP Registry, with categories that show the evidence behind them.

  • Filter by category, OS and complexity, and sort by stars or recency
  • Mirrored copies across agents fold into a single listing
  • Huge repositories are indexed lazily, so browsing stays fast
  • Every source shows when and against what it was verified

Installs you can read before they happen

One skill at a time, pinned to a commit. SkillDock stages it outside your Claude folders, inspects it, and shows the exact file changes before anything is written.

  • Security inspection flags risky patterns in the files you're about to add
  • Per-file add / modify / remove plan, then your approval
  • Backup, install, verify against the plan, roll back on any failure
  • Install a single skill from a multi-skill repository
  • Update with a local-modification guard, or pin a version

MCP servers without hand-editing JSON

Add, edit, import and export servers across user, project and local scopes, with secrets masked in the UI and out of logs.

  • Guided wizard, prefilled from the MCP Registry
  • See .mcp.json approval and scope-override state as Claude sees it
  • Test a connection: it only lists tools, never calls them, and asks first

Hooks and name conflicts, explained

See every hook from settings, plugins, managed policy and frontmatter, and the policy flags that govern them. Spot skills that shadow each other before they confuse Claude.

  • Honors allowManagedHooksOnly, disableAllHooks and workspace trust
  • Skill name conflicts shown with precedence
  • Disable a skill reversibly via skillOverrides

Skill Studio

Create and validate your own skills, agents and commands from templates or a wizard, then save to the scope you choose.

  • Live validation against the skill format
  • Static test cases; running real Claude is opt-in and approval-gated

Backups & crash recovery

Every change is backed up first. A journal restores state if the app dies mid-write. Restore from the Backups page.

Configuration editor

Edit settings JSON and Markdown safely. Unknown keys are preserved and concurrent edits are never overwritten.

Projects

Register the folders you choose and see project resources, settings inheritance and what overrides what.

Presets

Apply curated bundles of skills in one reviewed step, with the same plan, backup and verify flow.

Organization catalogs

Connect a team catalog by URL, GitHub file or local file. Versions are pinned and checksummed for consistent rollouts.

Plugins, agents & commands

Browse, enable and disable plugins through the claude CLI, and manage agents and commands by category.

Activity log

A local audit trail of every operation the app performed, so you can always see what changed and when.

11-tab skill inspector

Open any skill to see its docs, files, versions, scope, security notes and where it came from.

Light & dark, keyboard friendly

Dark and light themes, adjustable density, responsive layouts and an accessibility-tested interface.

How installs work

Nothing changes until you approve

Browsing or installing never executes anything from a resource. First launch is a read-only scan.

Pinto an exact commit
Stageoutside your Claude folders
Inspectfor risky patterns
Previewexact file changes
Approveyou decide
Back upthen install
Verifyagainst the plan; roll back on failure

Local-first

No backend and no telemetry. Your configuration leaves your device only when you fetch from GitHub or start an MCP server.

Sandboxed renderer

The UI has no Node access. Privileged work runs in the main process behind schema-validated IPC.

Asks before spending

Anything that starts a process or uses your Claude usage goes through a native macOS confirmation first.

Secrets stay secret

Masked in the UI, kept out of logs. An optional GitHub token for private repos lives in the macOS keychain.

FAQ

Questions

Is SkillDock made by Anthropic?

No. It's an independent, community-driven open-source project and not an official Anthropic application.

Does it send my configuration anywhere?

No. There's no account, backend or telemetry. Network is used only when you fetch from GitHub or the MCP Registry, or when you start an MCP server.

Will it break my existing setup?

It changes nothing without your approval, backs up every file first, verifies the result and rolls back on failure. Unknown settings keys are preserved.

What about Windows and Linux?

Packages are produced by CI but haven't been run by the maintainers, so they're unsupported for now. macOS is the supported platform.

Is the security scan a guarantee?

No. It's advisory pattern matching to help you review a skill. Always read the plan before approving.

Does it manage Claude Desktop chat skills?

Not yet. It manages what Claude Code reads on disk. Claude Desktop Chat, Cowork and cloud skills use separate configuration.

How much does it cost?

Nothing. It's MIT licensed.
